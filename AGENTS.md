## Design Context

Strategic and visual design context for this project lives in:

- [`PRODUCT.md`](PRODUCT.md) — users, register (brand), purpose, personality, anti-references, principles
- [`DESIGN.md`](DESIGN.md) — seed visual system (colors, typography, motion rules). Re-run `/impeccable document` after tokens are implemented.

**Impeccable harness:** installed locally in `.cursor/skills/impeccable/`. Use `/impeccable` or pinned shortcuts: `/shape`, `/craft`, `/document`, `/polish`, `/live`.

Run Impeccable commands from `kcic-pod/` (this folder). If the workspace root is `podcast/`, set `IMPECCABLE_CONTEXT_DIR=kcic-pod` or open `kcic-pod/` as the workspace folder so skills and context resolve correctly.

**After install:** restart Cursor (or reload window) if `/impeccable` or pinned commands do not appear. Enable Agent Skills in Settings → Rules; use Nightly channel if needed.
